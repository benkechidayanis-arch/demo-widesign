# Modèle de démo v5 : guide de construction

Copie le gabarit (gabarit.html) et adapte-le.

1. Le logo. Cherche le logo dans l'en-tête du site (balise img du header, ou og:image s'il s'agit clairement du logo). Télécharge-le avec curl dans $D/<id>/img/logo-client.<ext> (un SVG se convertit d'abord en PNG avec Playwright). Vérifie-le avec Read. python3 $O/logo_blanc.py logo-client.png logo-client-blanc.png, puis la couleur : python3 $O/couleur_site.py <site de l'entreprise> $D/<id>/img/logo-client.png donne acc, acc_ink, acc2, accd, rgb, rgbd, acc_ring. C'est la couleur dominante réellement utilisée sur leur site (titres, boutons, liens, fonds colorés), pas seulement celle du logo : c'est elle qui fait la ressemblance avec leur charte. Regarde le classement : si la première couleur est manifestement un élément étranger (bandeau cookies, widget de chat, bouton d'un réseau social), prends la suivante. Le texte posé sur l'accent prend acc_ink. Si le site n'a aucune couleur saturée, l'outil se rabat sur le logo (palette.py). Sans logo exploitable ou si palette.py renvoie null : nom de l'entreprise en texte (police des titres) et palette par défaut acc #E8601F, acc2 #FF9A5C, accd #C24B12, rgb 232,96,31, rgbd 194,75,18.

2. La carte. Trouve la commune de l'entreprise : https://geo.api.gouv.fr/communes?nom=<ville>&fields=code,codeEpci,centre&format=json (garde la commune du bon département). Télécharge les contours autour d'elle (environ 0,35 degré de chaque côté) : https://data.geopf.fr/wfs/ows?SERVICE=WFS&VERSION=2.0.0&REQUEST=GetFeature&TYPENAMES=ADMINEXPRESS-COG-CARTO.LATEST:commune&OUTPUTFORMAT=application/json&SRSNAME=EPSG:4326&BBOX=<lon_min>,<lat_min>,<lon_max>,<lat_max>,EPSG:4326 (longitude d'abord ; si 0 commune, vérifie l'ordre) dans $D/<id>/communes.json, puis python3 $O/carte_ville.py communes.json <code INSEE> <code EPCI> carte.svg. Le SVG s'insère tel quel à la place de celui du bloc .carte-w du gabarit ; l'étiquette .ct-nom porte le nom de la ville et sa position (left et top en pourcentage) se calcule depuis le cercle r="6" du SVG (cx/9, cy/9). Si l'IGN ne répond pas, retire le bloc carte et garde la liste des communes.

3. Construire. Copie le gabarit dans $D/<id>/index.html et adapte-le sans toucher à sa structure, ses polices, ses espacements ni ses animations : variables --acc, --acc2, --accd, --rgb, --rgbd ; logo blanc ; textes ; images de $D/<id>/img/ (noms parlants, JPEG de 1600 px au plus) ; carte ; mention du pied de page « Démo Widesign : un aperçu de ce que pourrait être le site de <nom>, visible jusqu'au <date d'expiration>. Démo non cédée, reproduction interdite. widesign.fr » (jamais « maquette proposée », « proposition » ni « réalisé pour vous » : c'est une démo qui montre le savoir-faire de Widesign, pas un travail livré) ; balise <meta name="robots" content="noindex, nofollow">. Aucune image chargée depuis un autre site (seules les polices Google sont autorisées). Le logo ne doit jamais être déformé : hauteur fixe, largeur automatique, align-self:flex-start dans un conteneur flex.
